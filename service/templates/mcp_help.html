Use from a chat assistant

The same designs, over the Model Context Protocol: ask Claude, or any MCP client, to plan a base-editing experiment in plain language.

Connect

Server address — streamable HTTP, nothing to install and no sign-in:

  • Claude Code: 
    claude mcp add --transport http bedesign {{ mcp_url }}
  • Claude, web or desktop: Settings → Connectors → Add custom connector, then paste the address.
  • Any other client: add it as a remote HTTP MCP server.

Use that address rather than this site's: the front end here gives up on a request after 60 seconds, which is less than a design is allowed to take.

Try asking

  • Design ABE8e-SpRY guides over MAP2K1's MANE transcript, then show me the ones that knock it out.
  • Which BE4max guides in exon 3 recreate a pathogenic ClinVar variant?
  • Give me the whole design file for that run as a TSV.

The tools

ToolWhat it does
resolve_gene Finds the gene a symbol, or the start of one, names.
list_transcripts A gene's transcripts, best choice first — MANE Select where there is one.
list_editors The base editors this engine knows, with each one's PAM and edit window.
design_guides Designs every guide over a transcript or a pasted sequence.
query_guides One page of designed guides, filtered and sorted.
get_clinvar_annotations Which known variant each edit would recreate.
export_run A whole output file, byte for byte as the command line writes it.

Worth knowing

  • design_guides hands back counts, per-exon coverage and a run handle rather than the guides themselves — a transcript routinely yields thousands, and which of them matter is the next question. query_guides reads them.
  • Every filter query_guides takes names a value the design already reported, so an assistant can only ask for something the result contains.
  • A design and the identical request from this website are one job writing one result, so asking the same question twice designs once.
  • Only so many designs run at a time. Turned away for a busy pool, an assistant is told to call again with the same arguments, and no work is lost — but starting designs is rate limited per address, so a retry is not free.
  • A non-zero error count means the engine stopped part-way through that transcript, so the designs are a partial answer rather than a final one.
